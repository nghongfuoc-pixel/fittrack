PROMPT XÂY DỰNG APP FITTRACK - DEMO 60 PHÚT (MOBILE-FIRST)
==========================================================

TỔNG QUAN
---------
Xây dựng ứng dụng theo dõi tập luyện thể hình tên "FitTrack", thiết kế mobile-first, giao diện tiếng Việt.
Mục tiêu trong 60 phút: tạo được demo chạy được trên điện thoại, người dùng có thể:
- Bắt đầu buổi tập
- Ghi weight / reps / sets
- Tính tổng volume
- Lưu buổi tập (local / mock) và xem lại được
- Xem lịch sử buổi tập (Log)

Ưu tiên trải nghiệm ghi tập mượt + dữ liệu được lưu (ít nhất trong phiên demo). Các tính năng nâng cao (biểu đồ phức tạp, CRUD routine đầy đủ, calendar, PR chi tiết...) làm đơn giản hoặc bỏ qua nếu hết thời gian.

YÊU CẦU KỸ THUẬT
---------------
- Framework: TanStack Start (React 19, Vite 7)
- Styling: Tailwind CSS v4, mobile-first, design tokens
- Backend / Deploy:
  - Không sử dụng Lovable Cloud
  - Code quản lý hoàn toàn qua GitHub
  - Trong 60 phút demo: dùng local state + localStorage (hoặc mock data) để lưu workout
  - Sau này sẽ tìm cách gắn database thật và deploy lên Render (hoặc dịch vụ tương đương: Railway, Fly.io, Vercel…)
- State: useState + localStorage (đơn giản cho demo)
- Forms: React Hook Form + Zod (dùng mức cơ bản nếu cần)
- Icons: Lucide React
- Charts: Tạm thời không bắt buộc
- Ngôn ngữ giao diện: Tiếng Việt 100%

THIẾT KẾ UI/UX MOBILE-FIRST
--------------------------
Navigation: Bottom tab bar 5 tab (thumb-friendly):
1. Home
2. Routines
3. Log
4. Stats
5. Profile

Các nút đủ lớn để chạm, ưu tiên trải nghiệm điện thoại.

CÁC MÀN HÌNH CHÍNH (PHIÊN BẢN DEMO)
-----------------------------------
1. Home:
   - Tiêu đề "Xin chào"
   - Nút CTA lớn: "Bắt đầu tập ngay"
   - Buổi tập gần nhất (nếu có)

2. Active Workout:
   - Chọn bài tập (danh sách mẫu sẵn)
   - Thêm / xóa set

   - Nút "Hoàn thành buổi tập" → tính total volume → lưu vào localStorage

3. Routines:
   - Hiển thị 1–2 routine mẫu (hardcode)
   - Nút "Tập routine này" → chuyển sang Active Workout

4. Log:
   - Danh sách buổi tập đã lưu (ngày, total volume, số bài)
   - Xem chi tiết buổi tập
   - Dữ liệu lấy từ localStorage

5. Stats & Profile:
   - Placeholder đơn giản (tiêu đề + text "Đang phát triển")

CẤU TRÚC DỮ LIỆU (CHO DEMO – LOCALSTORAGE)
------------------------------------------
Lưu dưới dạng JSON trong localStorage, cấu trúc gần với database thật để dễ chuyển sau này:

Workout object:
{
  id: string (uuid hoặc timestamp),
  name: string,
  startedAt: string (ISO),
  completedAt: string (ISO),
  totalVolume: number,
  durationSeconds: number,
  exercises: [
    {
      exerciseId: string,
      exerciseName: string,
      sets: [
        { setNumber: number, weight: number, reps: number, completed: boolean }
      ]
    }
  ]
}

Danh sách exercises mẫu (hardcode):
- Bench Press, Squat, Deadlift, Overhead Press, Barbell Row, Pull-up…

LƯU Ý DỮ LIỆU
-------------
- Luôn lưu weight theo kg
- totalVolume = tổng (weight × reps) của các set đã hoàn thành
- Dùng localStorage để dữ liệu còn sau khi reload trang
- Cấu trúc dữ liệu viết sẵn để sau này dễ chuyển sang PostgreSQL khi deploy lên Render

----------------
